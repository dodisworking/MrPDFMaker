# MrPDF - File to PDF Converter

A web application that converts files (images, HTML, text) to PDF format.

## 🚀 Quick Start

1. **Frontend**: Hosted on GitHub Pages
2. **Backend**: Must be deployed separately (see DEPLOYMENT.md)

## 📁 Project Structure

- `public/` - Frontend files (HTML, CSS, JavaScript, images)
- `server.js` - Node.js backend server
- `package.json` - Dependencies

## ⚙️ Setup

1. Install dependencies: `npm install`
2. Create `.env` file from `.env.example`
3. Start server: `node server.js`

## 📝 Notes

- GitHub Pages can only serve static files
- Backend must be deployed to Railway/Render/Heroku/Cloud Run
- Update `public/index.html` with your backend URL after deployment

See DEPLOYMENT.md for detailed instructions.
