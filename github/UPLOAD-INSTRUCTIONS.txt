═══════════════════════════════════════════════════════════════
  UPLOAD TO GITHUB - SIMPLE INSTRUCTIONS
═══════════════════════════════════════════════════════════════

STEP 1: Go to GitHub
   → https://github.com/dodisworking/MrPDFMaker
   → Click "Add file" → "Upload files"

STEP 2: Upload Everything
   → Drag and drop ALL files from this "github" folder
   → OR select all files and upload

STEP 3: Commit
   → Scroll down
   → Click "Commit changes"

STEP 4: Enable GitHub Pages (if not already)
   → Go to Settings → Pages
   → Source: Deploy from a branch
   → Branch: main, folder: / (root)
   → Save

STEP 5: Your site will be at:
   → https://dodisworking.github.io/MrPDFMaker/

═══════════════════════════════════════════════════════════════
  IMPORTANT: Backend Must Be Deployed Separately!
═══════════════════════════════════════════════════════════════

GitHub Pages can't run server.js. You need to:

1. Deploy backend to Railway/Render/Heroku
2. Get the backend URL (e.g., https://mrpdf.railway.app)
3. Edit public/index.html line 11:
   Change: window.API_BASE_URL = '';
   To:     window.API_BASE_URL = 'https://your-backend-url.com';

See DEPLOYMENT.md for detailed backend deployment steps.
